What the link statuses mean
Live
The original link worked at the last check.
Alternative
The original link is broken. A working page for the same guide replaces it.
Broken
The original link no longer works and no alternative was found. Try the Wayback archive.
Unverified
The website blocked the check or did not answer. The link may still work.
No link
The entry has no web address.
For example: beetles, lichen or BSBI

      About this catalogue

      ID Resource Signpost Revived is a restored copy of the Field Studies Council's ID Signpost, a crowdsourced catalogue of UK biological identification resources. Every link was rechecked, and archived copies were added from the Internet Archive.
